# TruTicket Android App — Installation Guide

This guide explains how to install the latest Android preview APK for TruTicket on your phone.

> **Note:** This is a preview build for testing only, not a Google Play Store release.

---

## Download Link

Download the latest APK directly from GitHub Releases:  
🔗 **[TruTicket Latest Android Release](https://github.com/brajesh1210/TruTicket/releases/tag/latest-android)**

- Tap **`TruTicket.apk`** (or the versioned `TruTicket-<sha>.apk`) under **Assets** to download.

---

## Installation Steps

1. **Open the release link** above in your Android phone's web browser (e.g. Chrome).
2. **Download the APK file** (`TruTicket.apk`).
3. **Allow unknown app installation** if prompted:
   - When Android alerts: *"For your security, your phone is not allowed to install unknown apps from this source"*.
   - Tap **Settings** on the prompt and toggle **Allow from this source** (or navigate to *Settings > Apps > Special app access > Install unknown apps > Chrome* and enable it).
4. **Install**: Return to the downloaded file or notification and tap **Install**.
5. **Open**: Once installation finishes, tap **Open** to launch the TruTicket app.

---

## Updates & Troubleshooting

- **Updating the app:** When a new build is published, downloading and installing the new APK will automatically update over the existing app as long as the signing key matches (version codes auto-increment with every cloud build).
- **"App not installed" / Package conflict error:** If Android shows *"App not installed"* or a signature conflict warning when updating, uninstall your existing TruTicket app first, then install the newly downloaded APK.
